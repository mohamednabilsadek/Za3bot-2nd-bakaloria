إجابة 16

الحوسبة السحابية تعالج وتخزن البيانات على خوادم بعيدة عبر الإنترنت، لذلك تناسب التخزين والخدمات المشتركة لكنها قد تتأثر بزمن الشبكة. أما الحوسبة الطرفية فتعالج البيانات قرب الجهاز أو المستشعر لتقليل زمن الاستجابة. مثال السحابة: حفظ ملفات المدرسة. مثال الحافة: معالجة بيانات مركبة محليًا لاتخاذ قرار كبح سريع.

16: الاحتواء يحد الانتشار، الاستئصال يزيل السبب، الاستعادة تعيد الخدمة. 17: الدروس المستفادة تحول النتائج إلى تحسينات. 18: الأثر حجم الضرر، الاحتمالية ترجيح الوقوع. 19: التحقق ← الاحتواء ← الاستئصال ← الاستعادة. 20: معلومات إضافية: نوع الأصول وقيمتها والأثر المالي والتشغيلي.

Quiz 08

16: Frontend يعرض ويجمع، Backend يعالج ويقرر. 17: Data Layer تخزن وتسترجع وقد تشمل قواعد بيانات وذاكرة مؤقتة وخدمات. 18: Frontend → Backend → Data Layer → Backend → Frontend. 19: Frontend يعرض، Backend يتحقق، Data Layer تخزن. 20: افحص Frontend (أرسل الطلب؟)، Backend (أرجع نتيجة؟)، Data Layer (يوجد منتجات؟).

Quiz 09

16: Client يرسل الطلب، Server يعالجه ويرد. 17: GET لطلب مورد، POST لإرسال بيانات. 18: 404 المورد غير موجود، 500 خطأ خادم. 19: Client → Request عبر HTTPS → Server يعالج → Response برمز حالة. 20: API تحدد التبادل، JSON تمثل البيانات، HTTPS يحمي القناة.

Quiz 10

16: HTML للبنية، CSS للمظهر، JavaScript للسلوك. 17: Semantic HTML يمنح عناصر معنى يفهمه قارئ الشاشة. 18: Responsive يتكيف مع الشاشات، Mobile First يبدأ من الهاتف. 19: تحسينات: ترتيب تركيز واضح + عناصر دلالية + تباين. 20: HTML دلالي + CSS متجاوب + دعم لوحة مفاتيح وقارئ شاشة.

Quiz 11

16: التلفزيون وصول واسع وأحادي الاتجاه، الموقع تفاصيل وتفاعل ويحتاج إنترنت. 17: وسائل التواصل سريعة لكن قد لا تكفي للتفاصيل الطويلة. 18: البريد الإلكتروني للفئات المحددة. 19: TV/Radio لكبار السن، وسائل التواصل للطلاب، موقع للتفاصيل. 20: وسائل التواصل للنشر، موقع للتفاصيل، بريد للتفاعل المباشر.

Quiz 12

16: Contrast للتمييز، Proximity لتجميع المرتبط. 17: Usability سهولة إنجاز المهمة، Accessibility إتاحة لأصحاب القدرات المختلفة. 18: Persona تمثيل لمستخدم مبني على بحث. 19: ضع زر الإجراء الرئيسي في منطقة يسهل الوصول إليها. 20: عناوين متشابهة = Contrast، محاذاة عشوائية = Alignment، مسافات غير منطقية = Proximity.

Quiz 13

16: النوعي يجيب لماذا، الكمي يجيب كم. 17: PV عدد المشاهدات، CVR نسبة تحقيق الهدف. 18: التقييم الإرشادي مفيد لكن لا يغني عن المستخدمين الحقيقيين. 19: Web Analytics ← تحديد المكان، Usability Testing ← فهم السبب. 20: CVR كمي + اختبار قابلية استخدام نوعي.

Quiz 14

16: Plan تخطيط، Do تنفيذ، Check قياس، Act تصرف. 17: قد يكشف الاختبار أن المشكلة مصاغة خطأ فيرجع للتعريف. 18: Prototype نموذج، Test تجربة؛ لا يدمجان. 19: نسختان تختلفان في نص الزر فقط، مقياس CVR. 20: Empathize ← Define ← Ideate ← Prototype ← Test ← PDCA.
